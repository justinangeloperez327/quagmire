# Changelog

Changes are recorded here before being assigned to a published release. Quagmire
uses the [release policy](docs/releases.md); no version has been released yet.

## Unreleased

### Added

- Rust compiler foundation with source loading, positions, spans, and diagnostics.
- One library with documented boundaries for the later compiler stages.
- Rust 1.88.0 toolchain and Linux/Windows formatting, lint, and test checks.

- Group 2 first-subset grammar, module rules, and parsing ambiguity decisions.
- Component, expression, event, view, keyed-list, and escaping specifications.
- Illustrative `.qg` source examples; these are not executable yet.
- Required language documents in the repository checker.

- Group 1 project scope and developer experience principles.
- Architecture decisions for Rust compiler tooling, `.qg` source files,
  JavaScript modules, direct DOM updates, CSS animation, and optional WebAssembly.
- Browser target and compatibility policy.
- MIT license, contribution guidance, and security reporting policy.
- Versioning and release strategy, plus the Group 2 grammar handoff.
- Repository formatting configuration and an offline foundation checker.
- Continuous integration for branch pushes and pull requests.
